# Advanced Algorithms Portfolio

This directory contains implementations and visualizations of advanced algorithmic concepts, focusing on computational complexity, NP-complete problems, and optimization techniques.

## Projects

### 1. Partitioning Problem
**Path:** `Partision/`  
**Status:** ✅ Complete

An interactive demonstration of the classic 2-partition problem, featuring:
- **Decision Algorithm:** Exponential O(2^n) exact solution using bitmask enumeration
- **Greedy Heuristic:** Polynomial O(n log n) LPT approximation
- **Exact Optimization:** Finds minimum difference partition for small inputs
- **Special Case Analysis:** Polynomial solution for restricted input domains

**Assignment Requirements Met:**
- ✅ Part A: Exponential decision algorithm with complexity analysis
- ✅ Part B: Greedy heuristic with success/failure cases
- ✅ Part C: Polynomial algorithm for special case (x/2x inputs)

**Key Features:**
- Real-time performance metrics
- Interactive input generation with seeding
- Visual comparison of algorithm performance
- Step-by-step heuristic visualization
- Workload growth analysis (2^n demonstration)

## Complexity Theory Demonstrations

All projects in this collection emphasize:
1. **Exponential vs Polynomial:** Direct comparison of brute-force and heuristic approaches
2. **NP-Completeness:** Practical demonstration of intractable problems
3. **Algorithm Trade-offs:** Accuracy vs speed, optimal vs approximate
4. **Scalability Analysis:** Identifying feasible input sizes
5. **Visual Learning:** Interactive exploration of algorithm behavior
